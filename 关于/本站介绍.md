
简介
====

本站是使用 [ASBM](https://github.com/tai-woi/asbm) 项目搭建的演示站，用于探索 ASBM 项目的可行性，指引和发现新的需求，同时为参与者提供一个留存和分享精彩记录的园地。

除了基本的 ASBM 代码，目前本站内容全部使用 Markdown 格式。

ASBM 是 Any Server But Markdown 的缩写，目标是无论使用哪种网页服务器（Nginx, Apache, Caddy, Lighttpd, IIS，甚至开发工具 Python, PHP, VS Code, WebStorm, Xed-Editor 等自带的微服务器），用户都可以使用浏览器实时访问站内的 Markdown 文件，并且浏览器会自动将文件结构和文字转换为方便查阅的 HTML 排版格式。

注意：基于 ASBM 的运作原理，所有在本站发布的内容都是公开的。*对于任何不想公开的信息，请不要在本站发布*，谢谢！

目前很多内容还在摸索阶段，欢迎大家[参与讨论](https://github.com/tai-woi/playbook/discussions)。
