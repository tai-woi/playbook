极度危险
====

纸面富贵
----

+ 财务矛盾表现：净利润为正，但经营性现金流持续为巨额负数。
+ 可能的原因或问题：利润靠应收账款（白条）支撑；或者通过关联交易虚增收入，实际没有现金进账。
+ 危险逻辑：利润是假的或难以收回。公司赚的是“纸面财富”，却要真金白银支付工资和利息，极易引发债务违约。


存贷双高
----

+ 财务矛盾表现：货币资金（账上现金）充裕，但同时借入高息贷款（存贷双高）。
+ 可能的原因或问题：账上现金可能被大股东占用（如担保冻结）、或是虚增的“幽灵存款”；真实资金链紧张，不得不借高利贷。
+ 危险逻辑：典型的康美药业/康得新式陷阱。一旦市场质疑，银行抽贷，瞬间崩盘。


非标红灯
----

+ 财务矛盾表现：审计报告出具“保留意见”或“无法表示意见”。
+ 可能的原因或问题：会计师认为存在重大错报，或无法获取充分审计证据（尤其是关于境外资产或大额往来款）。
+ 危险逻辑：这是最直白的红灯。根据交易所规则，连续“非标”可能直接触发退市风险警示（*ST）。



高度危险
====

烧钱冲量
----

### 利润率

+ 财务矛盾表现：营业收入增长，但毛利率和净利率大幅下滑。
+ 可能的原因或问题：靠“烧钱”低价冲量，或者成本确认滞后；也可能是将原本应资本化的利息费用化了，掩盖真实成本。
+ 危险逻辑：说明主业竞争力急剧下降，一旦价格战停止，收入立刻萎缩，净利润变脸极快。

### 应收账款或存货

+ 财务矛盾表现：收入增长10%，但应收账款或存货增长50%以上，且计提比例很低。
+ 可能的原因或问题：下游压货或放宽信用政策冲业绩（提前确认收入）。
+ 危险逻辑：若存货库龄过长，后续将面临巨额减值“暴雷”。


借新还旧
----

+ 财务矛盾表现：短期借款和应付债券大增，但投资活动现金流显示“购建固定资产”支出很少。
+ 可能的原因或问题：借来的钱没有投入生产，而是用于偿还旧债利息或流向关联方（大股东拆借）。
+ 危险逻辑：属于庞氏融资迹象，公司已失去“造血”能力，只能借新还旧，违约概率极高。


资产减值
----

+ 财务矛盾表现：资产减值损失（*商誉/存货/应收账款*）集中在第四季度暴雷。
+ 可能的原因或问题：前三个季度隐瞒坏账，年底“一次性洗澡”；或此前并购的子公司业绩对赌到期，商誉泡沫破裂。
+ 危险逻辑：说明管理层诚信存疑，且未来几年利润会被高额的摊销持续侵蚀。


流动性枯竭
----

+ 财务矛盾表现：大股东股权质押比例 > 80%，且公司频繁变更会计事务所。
+ 可能的原因或问题：大股东流动性枯竭，有掏空上市公司动机；换所通常为了寻求更“宽松”的审计意见。
+ 危险逻辑：直接破坏“造血”能力，可能导致优质资产被动“贱卖”，甚至发生挤兑效应。



中度危险
====

主业无力
----

+ 财务矛盾表现：非经常性损益贡献超过净利润的50%。
+ 可能的原因或问题：靠卖资产、政府补贴或理财收益拼凑利润，剔除后主业实际亏损。
+ 危险逻辑：说明公司业绩不可持续。


虚增资产
----

+ 财务矛盾表现：研发投入资本化率突然大幅提高。
+ 可能的原因或问题：将大量研发支出（本该计入费用）转化为“无形资产”资产，以此美化当期利润。
+ 危险逻辑：属于利润调节手段。虚增的资产未来会转化为巨额摊销，吞噬未来利润。


裁员降薪
----

+ 财务矛盾表现：员工薪酬总额下降，但员工人数增加。
+ 可能的原因或问题：要么是大规模裁员降薪（经营困难），要么是将正式员工转为外包（规避社保，但降低员工忠诚度）。
+ 危险逻辑：对于证券公司而言，人才是第一生产力。薪酬负增长意味着核心团队流失风险，服务能力下滑。



轻度危险
====

利润受限
----

+ 财务矛盾表现：母公司报表与合并报表的净利润差异巨大。
+ 可能的原因或问题：利润主要来自非全资子公司（少数股东损益占比过高），或母公司本身亏损严重。
+ 危险逻辑：说明上市公司本部是个空壳，真正赚钱的资产不在上市公司完全控制下，利润分配权受限。


合法操纵
----

+ 财务矛盾表现：主要会计估计变更（如坏账计提比例下调）。
+ 可能的原因或问题：管理层的“合法”利润操纵手段，没有任何经营实质改善。
+ 危险逻辑：虽然不违规，但说明管理层倾向于报喜不报忧，投资者需下调对其诚信的评级。
