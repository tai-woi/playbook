认知奠基
====

实践价值投资策略，首先要做的是重塑投资世界观，必须先完成这三项认知转换，否则策略就是空中楼阁。

+ *股票是公司所有权，而非交易筹码*：这是最根本的认知。买股票就是成为这家公司的股东，你的收益最终来源于公司未来现金流的创造，而不是下一个人出更高的价钱。每次下单前问自己：如果股市关闭五年，我还愿意持有这家公司吗？
+ *市场是仆人，而非向导*：市场先生每天报价，时而狂躁（给极高价），时而抑郁（给极低价）。他的作用是为我们服务，而不是指导我们。价格波动本身不是风险，本金的永久性损失才是真风险。
+ *安全边际是防身的铠甲*：用 4 毛钱买价值 1 块钱的东西，那 6 毛的差价就是安全边际。它是对自己认知可能出错的保护，也是对抗未来不确定性的缓冲。
+ *能力圈比“懂很多”更重要*：你不需要看懂所有行业，但必须诚实面对自己真正理解什么。无法判断一家公司十年后怎么赚钱，无法估算到那时现金流还有多少，就不应该碰它。
+ *真正的风险是永久性资本损失*：股价跌 20% 不等于风险，企业护城河崩塌、财务造假、需求永久萎缩、买入价格过高导致长期无法回本，才是真正的风险。


核心框架
====

好生意
----

### 赚钱容易

+ 毛利率、净利率高
+ 资本开支少，自由现金流好
+ 不需要持续大量融资

### 有定价权

+ 提价后客户仍愿意购买
+ 成本上升能转嫁给下游
+ 客户对价格不敏感

### 行业竞争格局清晰

+ 行业前几名市场份额稳定
+ 没有持续价格战
+ 新进入者难以颠覆

### 需求稳定或成长

+ 需求是否长期存在
+ 是否受技术迭代、政策变化冲击大

### 容易看懂

尽量选择简单、可理解、变化慢的生意。比如消费、医药、公用事业、部分制造和金融，通常比前沿科技更容易判断。

投资不是奥运会，不需要挑战高难度动作来证明自己。 我们赚的是“确定性”的钱，而不是“高难度”的钱。


好公司
----

### 护城河来源

+ 品牌：消费者愿意为品牌支付溢价
+ 网络效应：用户越多，价值越大
+ 转换成本：客户更换供应商成本高
+ 成本优势：规模、工艺、地理、资源等
+ 特许经营权：牌照、专利、政策壁垒

### 管理层

重点不是听管理层说什么，而是看他们做什么：

+ 资本配置能力：是回购、分红、再投资，还是盲目扩张？
+ 是否诚实：历史上是否兑现承诺，是否频繁变脸？
+ 是否与股东利益一致：持股比例、薪酬结构、关联交易
+ 是否专注主业：频繁跨界并购通常是危险信号

### 财务质量

核心不是利润表好看，而是：

+ 利润是否转化为现金
+ 资产负债表是否稳健
+ 应收账款、存货、商誉是否异常
+ 有息负债是否可控


好价格
----

好公司买贵了，也可能长期不赚钱。好价格的核心是：

+ 当前价格显著低于保守估计的内在价值
+ 估值处于自身历史低位
+ 自由现金流收益率具有吸引力
+ 股息率提供一定保护



研判指标
====

盈利能力
----

+ ROE 连续 5 年 > 15%
+ ROIC 连续 5 年 > 12%
+ 毛利率 > 30%
+ 净利率 > 10%


成长性
----

+ 营收复合增速 > 5%-10%
+ 扣非净利润复合增速 > 5%-10%
+ 不追求高增长，但要求稳定


现金流质量
----

+ 经营现金流 / 净利润 > 80%
+ 自由现金流连续 3 年为正
+ 资本开支占经营现金流比例合理


财务健康
----

+ 资产负债率 < 50%-60%
+ 有息负债 / EBITDA < 2
+ 流动比率 > 1.5
+ 货币资金充裕，短期偿债压力小


估值
----

+ PE 处于近 5 年历史分位 50% 以下
+ PB 处于近 5 年历史分位 50% 以下
+ 股息率 > 1.5%-2%
+ 自由现金流收益率 > 5%


剔除条件
----

+ 上市不足 3-5 年
+ ST、*ST
+ 市值过小，流动性差
+ 审计意见非标准无保留
+ 商誉占净资产比例过高
+ 频繁增发、配股、大额减持



行业调整示例
====

银行
----

###  安全性

- 不良贷款率 < 1.5%（优秀银行 < 1.0%）。衡量贷款中坏账的比例，越低越好。
- 拨备覆盖率 > 200%（稳健型 > 300%）。即“利润蓄水池”，越高表明抵御坏账风险的能力越强。
- 核心一级资本充足率 > 8.5%（国有大行通常 > 10%）。银行的“自有本金”厚度，防止破产的最后防线。
- 关注类贷款占比 < 2.5%。反映潜在的不良趋势，是前瞻性指标。

### 盈利能力

- 净资产收益率（ROE） 10%-15%。银行股价值投资的基石，长期维持 > 12% 为优秀。
- 净息差（NIM） > 1.8%（当前低利率环境下）。银行“进货（存款）出货（贷款）”的差价，越高赚钱越容易。
- 非利息收入占比 > 20%。理财、手续费等中间业务收入，占比高说明不单纯依赖放贷，抗周期能力强。

### 估值水平

- 市净率（PB） 0.5-0.8 倍（极值机会 < 0.5）。银行股核心估值锚，买入时低于净资产（破净）是常态，0.6 倍以下具较高安全边际。
- 市盈率（PE） 4-7 倍。因银行利润平滑，PE可作为辅助，高于8倍需警惕高估。
- 股息率 > 5%（优秀标的 > 6%）。价值投资的“保底收益”，高股息是银行股的重要吸引力。

### 负债结构

- 贷存比 70%-80%。比例过高（> 85%）说明资金紧张，过低（< 60%）说明资金利用率低。
- 活期存款占比 > 50%。活期占比越高，银行付息成本越低，是低成本负债能力的体现。

优先选*低PB（< 0.6）+ 高股息（> 6%）+ 高拨备（> 250%）*的组合，同时确保ROE稳定不滑坡。在行业低谷期（净息差下行时）分批买入，长期持有获取分红和估值修复收益。


保险
----

### 专属经营指标

- 内含价值（EV）增长率 ≥ 10%（年化）。低于此值说明新业务未能有效增值。
- 新业务价值（NBV） ≥ 5%。这是未来利润的领先指标，持续下滑则回避。
- 新业务价值率 ≥ 25%（保障型为主）。低于 20% 说明产品结构偏向低价值的理财型，资本消耗大。
- 综合成本率（财险核心） ≤ 100%（低于即承保盈利）。优秀财险公司应在 97%-99% 之间。
- 偿付能力充足率（核心/综合）：核心充足率 ≥ 50%，综合充足率 ≥ 100%（监管红线）。过低有融资压力，过高则资金闲置。

### 财务安全与盈利指标

- 净资产收益率（ROE） ≥ 12%（长期平均）。寿险靠杠杆，低于 10% 则价值毁灭。
- 总投资收益率 ≥ 4.5%（长期假设一般为 5%）。持续低于 4% 则利差损风险显著。
- 负债成本率（资金成本） ≤ 3%（当前利率环境下）。高于投资收益率则形成利差损。
- 退保率 ≤ 5%。过高说明产品吸引力或销售品质有问题，会抽干流动性。

### 估值与价格指标

- PEV（股价/内含价值）：极度低估 < 0.6倍（可重仓）；合理区间： 0.8-1.2 倍；高估： > 1.5倍（需减仓）。（注意：纯财险公司用PB，不用PEV）
- PE ≤ 10倍（EV增长稳定的前提下）。若PE > 15倍且EV不增长，则为陷阱。
- 股息率 ≥ 3%（作为安全垫）。优秀保险股在低估区间股息率常达 4%-5%。

### 宏观与利率参考

- 10年期国债收益率 > 3% 对保险最有利（利差扩阔）； < 2.5% 需警惕估值承压。
- 权益市场趋势：沪深300年度正收益环境，保险股弹性最大；熊市中PEV破 0.6 倍是常见买点。

综合买入条件：*PEV < 0.7倍 + NBV正增长 + ROE ≥ 12% + 股息率 > 3%*，四者同时满足即为保险股的价值击球区。

以上指标可直接去各保司官网的“公开信息披露”栏查阅。核心财务数据（EV、NBV、OPAT）仅在半年报及年报中披露。


公用事业
----

### 估值与安全边际

+ 市盈率（PE） 15-20 倍（成熟市场稳定型公用事业）。若低于 15 倍可能被低估，高于 25 倍需警惕溢价过高。
+ 市净率（PB） 1.5-2.5 倍。因资产较重，PB过高（> 3倍）需小心；若低于 1 倍（破净）则具备显著安全边际。
+ 股息率 4%-6% 为合理区间。需显著高于当地10年期国债收益率（通常高出 1-2 个百分点才具吸引力）。
+ 企业价值/息税折旧摊销前利润（EV/EBITDA） 8-12 倍。此指标比PE更适合衡量重资产、高折旧的公用事业公司。

### 盈利与现金流质量

+ 自由现金流（FCF）与净利润比率：要求 > 80%（最好持续大于1）。公用事业盈利需有真实现金支撑，防止账面利润虚高。
+ 股息支付率（派息比率）：参考 60%-80%。过高（> 90%）则分红难持续，过低（< 40%）则可能未重视股东回报。
+ 经营现金流/流动负债：要求 > 0.5。衡量短期偿债压力和现金流覆盖能力。

### 财务风险与资本结构指标

+ 资产负债率：警戒线 < 65%，优秀线 40%-55%。因项目前期投入大，负债普遍偏高，但超过 70% 需高度警惕。
+ 利息保障倍数（EBIT/利息）：要求 > 3 倍，稳健值 5 倍以上。确保盈利能轻松覆盖利息支出。
+ 有息负债/ EBITDA：参考 < 5 倍。衡量用经营利润偿还全部有息债务所需年限。

### 监管与运营效率指标

+ 监管允许的股本回报率（ROE）：参考 8%-10%（受监管管制）。若ROE持续高于此区间，可能面临监管下调价格的压力。
+ 净资产收益率（ROE）：参考 10%-14%。需结合杠杆看，过高杠杆推高的ROE需打折看待。
+ 资本支出（CAPEX）/ 折旧摊销：参考 1.0-1.5倍。接近1倍为维持性资本，过高（> 2 倍）则吞噬自由现金流，影响分红。

### 补充定性关注点

+ 监管政策稳定性：所在地区是否允许及时调价以传导燃料成本（如电价联动机制）。
+ 剩余特许经营权年限：若低于 10 年，估值需大幅打折。
+ 新能源转型敞口：传统火电/水务是否面临环保成本激增，或是否有明确的新能源替代路线图。

核心提示：以上数值均基于低利率（如美国 10 年期国债 2%-3%）环境。若当前*无风险利率大幅上升，所有估值和股息率要求需同步上移*（例如股息率需高于国债收益率150-200个基点）。投资公用事业的核心逻辑是“赚取稳定股息而非资本利得”，因此建议优先看“现金流质量”和“股息率”，再参考估值。


大消费
----

### 盈利能力

- 毛利率 > 40%（品牌溢价能力）。若低于 30%，说明处于红海竞争。
- 净利率 > 15%（费用控制能力）。这是消费龙头与平庸者的分水岭。
- 净资产收益率（ROE） > 20%（且持续多年）。巴菲特最看重，要求非高杠杆（负债率低）驱动。
- 扣非净利润增速 > 10%-15%。需匹配收入增速，避免“赚应收款”的虚假繁荣。

### 估值与回报

- 市盈率（PE）历史中位数以下 20% 分位，或 PE < 25-30倍（稳健型）。若增速超 20%，可放宽至 35 倍；若低于 10%，需警惕增速陷阱。
- 股息率 > 3.5%（显著高于国债收益率）。成熟消费股若无高分红，需有明确高增长理由。
- 自由现金流/净利润 > 80%。利润必须是真金白银，而非堆在仓库里的存货。
- PEG（市盈率/增速） < 1 或 < 1.5（即增速至少覆盖PE）。

### 经营安全

- 存货周转天数同比无明显上升。若大幅增加，暗示滞销（如服装、食品过期风险）。
- 预收款/合同负债同比正增长。这是下游打款的“饥饿程度”，是消费品强势的领先指标。
- 资产负债率 < 50%（剔除银行/地产）。消费股若负债过高，经营波动时现金流易断裂。
- 市占率行业前3，且份额逐年提升。这是抗通胀提价权的保障。

特别注意：以上数值在高端白酒（可容忍高PE低周转）和大众快消（必须看股息和周转率）之间差异极大。价值投资消费股时，“PE绝对值低”不如“ROE稳定性高”重要，宁可买 25 倍PE的茅台，也不买 10 倍PE的杂牌乳企。


能源
----

能源行业（特别是传统油气与新型电力）具有强周期、重资产、高波动的特性，这使得价值投资策略在该行业的应用，与投资金融或消费股有显著区别。

如果只记住一个核心逻辑，那就是：在能源行业，价值投资不是“买了就不动”，而是“在景气低谷买现金流，在景气高点买成本优势”。

针对能源行业，价值投资者应重点关注以下四大类核心指标，按重要性排序如下：

### 生存与分红底线

能源行业负债率普遍较高，且产品价格不可控，资产负债表的质量是价值投资的安全垫。

+ 净债务 / EBITDA（息税折旧摊销前利润）倍数：这是能源行业最核心的偿债指标。安全阈值通常要求低于 2.0 倍。若高于 3.0 倍，一旦油价或电价下跌，公司可能面临再融资风险，股息也可能被腰斩，这不符合价值投资的“本金安全”原则。
+ 自由现金流（FCF）与股息覆盖率：不要只看股息率（静态），要看自由现金流是否至少是股息的 1.2-1.5 倍。只有自由现金流支撑的股息才是可持续的，才是“真价值”；若靠借债分红，则是价值陷阱。

### 盈利质量与成本护城河

能源产品是同质化的，唯一的护城河是成本最低。

+ 全周期保本成本（Breakeven Price）：对于石油，关注桶油操作成本+资本开支摊销的总成本；对于光伏，关注度电成本（LCOE）。价值投资者应在公司保本成本低于行业平均 15% 以上时重点关注。这确保在行业最糟糕的两年里，公司依然不亏损。
+ 储量替代率（Reserve Replacement Ratio）：针对上游油气。若该比率低于 100%，说明公司寅吃卯粮，账面利润靠消耗地下资产获得，这不是真正的“股东盈余”，而是价值损耗。

### 周期择时指标

价值投资在能源业最大的难点是择时。买得便宜比买好公司更重要。

+ 企业价值/经调整后的EBITDA（EV/EBITDAX）：这是能源业最常用的估值锚。历史分位数低于 20% 时，通常对应周期底部。注意，不要看PE（市盈率），因为能源行业利润波动极大，低PE往往对应周期顶部（利润最高时），是卖出信号，而非买入信号。
+ 远期期货曲线（Contango/Backwardation）：这是价值投资者在能源业的“秘密武器”。当远期价格曲线处于贴水（Backwardation，即远期价格低于近期）时，意味着高成本产能正在退出，这是价值回归的前兆；当远期大幅升水时，要警惕产能即将泛滥。

### 资本纪律与股东回报

能源行业很容易出现“利润一好就乱投资”的恶习，这会毁灭价值。

+ 资本开支 / 折旧摊销（Capex/DA）比率：最理想的数值在 1.0-1.2 之间。若该比率远大于 1.5，说明公司在大肆扩张，历史上这往往导致项目回报率下降；若该比率接近 1，说明公司在维持现有产能的同时，将多余现金用于还债或回购，这才是对股东负责任的态度。
+ 股东回报率（回购+股息）/ 市值：在能源行业，这一综合回报率若能达到 8%-10%，即便股价长期不涨，股东也能通过回购注销获得可观的每股价值提升。

### 区分价值与价值陷阱

投资能源股，*最危险的指标是“市盈率（PE）极低”*。当PE低于 5 倍时，这通常不是买入机会，而是周期即将见顶的信号。正确的做法是：在市净率（PB）接近历史低位、且自由现金流依然为正时，分批建仓。


医疗健康
----


### 护城河与研发效率

+ 研发费用资本化率：警惕资本化比例过高（> 40%）的公司，这常被用来美化当期利润，选择资本化率低或费用化处理更保守的企业。
+ 管线“终端市值”/研发投入比：估算当前在研管线若成功上市，潜在峰值销售额是当前年研发投入的多少倍（倍数越高，研发性价比越突出）。
+ 核心产品专利到期时间：对于仿制药或生物类似药，专利悬崖是价值毁灭的直接导火索，需确保 5 年内无重磅品种专利过期。

### 盈利质量与现金流

+ 经营活动现金流净额/净利润：长期 > 0.8 是底线，最好持续大于 1（说明利润是真金白银，而非堆积在应收账款或存货里）。
+ 应收账款周转天数：若该指标逐年显著上升，意味着医院或渠道压款严重，企业的议价权在削弱。
+ 销售费用率：在集采常态化下，该比率应呈下降趋势。若仍高居不下（如 > 40%），说明产品缺乏临床硬实力，依赖灰色推广。

### 成长天花板与定价权

+ 核心单品营收/总营收：若占比 > 70%，需警惕“大品种依赖症”；若 < 30%，则需评估其他业务是否过于分散、拉低整体毛利率。
+ 毛利率与净利率的差值：差值过大（如毛利 80%、净利仅 15%）说明管理费用或销售费用吞噬了大部分利润，产品虽好但公司运营效率低下。
+ 人均单产（营收/员工总数）：对比同行业，若持续低于平均水平，说明人效低下，规模效应未体现。

### 估值安全边际

+ 市盈率（PE） vs 行业历史中位数：不只看绝对数值，重点看当前PE处于近 5 年历史区间的什么百分位（低于 30% 分位才具吸引力）。
+ PEG（市盈率/净利润增速）：对于稳定增长型医疗股，PEG < 1 是较安全的买入区间；对于高创新药企，需改用PEG（基于峰值利润折现）。
+ 股息率（仅针对成熟药企/器械）：若一家无高增长预期的医疗龙头，股息率低于国债收益率，则缺乏防御性价值。

对医疗股，“管理层股权激励行权条件”比上述财务数据更前置——若行权门槛仅设定为“营收增长”而非“核心产品销量或自由现金流”，则需高度警惕，这往往是短期市值管理的信号。长期主义者，要敢在行业性黑天鹅（如集采过度恐慌）中加仓，而回避政策利好催化的短期高潮。

### 细分领域

医疗健康行业并非“雨露均沾”，价值投资要寻找*需求刚性+竞争格局稳定+政策免疫或受益*的交集。结合当前（2026年）国内环境，建议关注以下细分领域，并远离“价值陷阱”：

#### 优先关注（长坡厚雪）

+ 创新器械中的“小型化/家用化”赛道：避开医院集采压价，直接面向C端（消费者），且耗材复购率高。价值核心看“单用户年贡献收入”和“医保报销比例变化”——若自费比例高，则定价权在厂家手中。
+ 刚性需求的“专科服务”连锁：消费医疗属性，不受DRG（疾病诊断相关分组）控费冲击。重点跟踪“单店成熟期利润率”和“新店爬坡周期”，若老店利润稳定且新店亏损收窄，是底部信号。
+ CXO（医药研发外包）中的“细分寡头”：全球生物医药投融资虽冷，但中小Biotech为降本会加大外包。筛选标准：在手订单/年收入 > 1.5，且来自欧美客户的收入占比未因地缘政治骤降。
+ 血制品与麻醉镇痛药（行政准入壁垒极高）：牌照管制，供给端长期受限，需求端刚性（手术、重症）。只需关注采浆量增速和产品批签发量，几乎不需担忧价格战。

#### 谨慎规避（价值陷阱）

+ 普通仿制药及低值耗材（输液、注射器）：集采已杀到“骨髓”，且同质化严重，即便PE跌至个位数，也是“价值毁灭型”低估值。__受政策影响的典型__
+ PD-1/GLP-1等热门靶点的跟风创新药企：除非是已形成“联合用药矩阵”的头部，否则单一大品种在2026年面临医保续约降价和后来者内卷，PEG极易由正转负。
+ 持续关注政策变化和历年财务数据变化情况，避开在高估值泡沫期介入。


工业制造
----

### 盈利质量

+ ROIC（投入资本回报率）：最核心指标，需长期（5-10年）高于资本成本（WACC），且稳定少波动。
+ 自由现金流/净利润：比值 > 0.8 为佳，防止“纸面利润”被存货和应收款吞噬。
+ 毛利率与净利率：关注二者走势是否背离（若毛利率稳、净利率升，说明费用控制强）。

### 资产效率

+ 固定资产周转率：衡量厂房设备产出效率，需结合产能利用率看趋势。
+ 存货周转天数：制造业关键，异常增加可能预示需求放缓或库存积压。
+ 应收账款周转天数：反映对下游客户的议价权，持续延长是危险信号。

### 财务安全

+ 资产负债率：工业制造建议 < 60%，且需看有息负债占比（而非预收款等无息负债）。
+ 利息保障倍数：> 5 倍为安全，确保下行周期不至于利息压垮利润。
+ 经营性现金流/流动负债：衡量短期偿债的“即时火力”。

### 成长与再投资

+ 研发费用率：需结合转化效率（看专利或新品收入占比），过高或过低都需警惕。
+ 资本支出/折旧摊销：比值 > 1.5 表示在扩张，但需确认新增产能有订单支撑；长期接近 1 则偏向维持性投入。
+ 人均产值（或人均利润）：自动化升级和管理的最终体现，持续提升为优。

### 行业地位与定价权

+ 市占率变化：逆周期时份额是否扩张，是判别龙头成色的关键。
+ 客户集中度：前五大客户占比 < 30% 为安全，避免被下游大客户压价。
+ 产品差异化指标（定性辅助）：如定制化比例、售后收入占比、客户转换成本。

### 估值与股息

+ EV/EBITDA（企业价值/息税折旧前利润）：比PE更适合跨周期比较制造业（考虑折旧差异）。
+ 股息支付率：30%-50% 较为健康，既回报股东又保留发展资金。
+ 自由现金流收益率（FCF/市值）：> 5% 往往提供较好的长期买入安全垫。

最后提醒：*工业制造属强周期行业，回避在行业顶峰时以“成长股”估值买入*。价值投资的关键在于长期跟踪上述指标的季度变化趋势，而非单一时点数值。当ROIC稳定、现金流充沛且市占率逆势提升时，往往是好的介入窗口。


特殊化工与材料
----

核心是规避周期性波动陷阱，寻找具有“护城河”且能持续创造现金的企业。

### 盈利质量与护城河

+ 净资产收益率（ROE）：要求连续 5-10 年稳定在 15% 以上，且主要依赖高净利率（而非高杠杆或高周转），这代表产品的独特性和定价权。
+ 毛利率与净利率的稳定性：关注行业低谷期（如原油暴跌或下游需求疲软时）毛利率的跌幅是否远小于同行，这印证了成本转嫁能力。
+ 研发资本化率：警惕将大量研发支出资本化（虚增利润）的企业，偏好研发费用全部费用化且仍能保持高盈利的公司。

### 财务安全与抗周期能力

+ 自由现金流（FCF）与净利润比率：长期要求该比率 > 80%（即赚到的钱基本都变成了真金白银），避免因大量设备维护更新而吞噬利润的“纸面富贵”。
+ 有息负债/总资本比率：特殊化工重资产，要求该比率低于 40% 且短期借款远小于账面现金，确保在行业去库存周期中不会资金链断裂。
+ 固定资产周转率：衡量每一元设备产生的收入，如果该指标持续下滑，说明产能过剩或产品正在被替代。

### 成长逻辑与空间

+ 特种品销量增速 vs 价格增速：优先选择“销量增长为主导”的企业（代表渗透率提升），而非仅靠涨价驱动的企业（易受替代品冲击）。
+ 在建工程与折旧的比值：比值 > 1.5 且在建工程主要为“技术升级”而非“扩同质化产能”，预示着未来有高附加值产品放量。
+ 下游应用结构变化：关注消费电子、半导体、新能源、医药等高端领域收入占比是否逐年提升（需在年报中手动拆解）。

### 估值与安全边际

+ 企业价值/息税折旧摊销前利润（EV/EBITDA）：比市盈率（PE）更适合重资产化工，因为剔除了折旧政策差异，建议低于行业历史中位数 30% 时介入。
+ 股东盈余折现（DCF）下的极限压力测试：假设未来 3 年零增长，计算当前股价对应的隐含回报率是否高于无风险利率的 2 倍。
+ 股息率与回购记录：在行业低谷期，稳定的股息率（> 2%）和持续的回购是管理层对股价信心的直接体现，也是长期持有的“保底收益”。



退出机制
====

逻辑止损
----

不管盈亏，只要当初买入的核心逻辑被证伪，就退出。触发条件示例：

+ 主营产品被新技术替代
+ 核心客户流失且短期无法恢复
+ 管理层出现严重诚信问题
+ 财务数据连续两年恶化，且并非周期因素
+ 监管政策导致商业模式不可持续


估值止盈
----

当价格明显高于内在价值，安全边际消失时，分批卖出。触发条件示例：

+ PE 超过历史 5 年 70%-80% 分位
+ 自由现金流收益率 < 3%
+ 股息率明显低于长期均值
+ 市值明显超过乐观情形下的内在价值


机会成本换仓
----

如果另一个标的的预期年化回报明显高于当前持仓，同时风险更低，可以换仓。比较方法：

+ 计算两个标的未来 3-5 年的预期回报
+ 考虑确定性、回撤风险、流动性
+ 如果新标的优势明显，则分步换仓
