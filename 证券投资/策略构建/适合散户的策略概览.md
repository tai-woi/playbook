从散户的实际约束出发（资金量小、信息劣势、时间有限、无法做空/加杠杆受限、交易成本敏感），适合散户的策略可以按决策依据和操作范式两个维度系统梳理。

技术分析类
====

技术面炒股整体适合：有时间盯盘、能执行纪律、接受低胜率的散户。*不建议作为唯一策略。*

趋势跟随
----

+ 逻辑：不预测顶底，突破买入、跌破卖出，靠盈亏比赚钱。
+ 散户适配：需严格纪律，胜率约40%，震荡市磨损大。适合能接受连续止损、有盯盘时间者。
+ 工具：均线系统、N日新高突破、ATR止损。

均值回归
----

+ 逻辑：价格偏离均值过远会回归。RSI超卖买入、布林带下轨买入、偏离均线过多回归。
+ 散户适配：震荡市有效，趋势市易被"接飞刀"。适合震荡品种（如宽基ETF）。

形态突破
----

+ 逻辑：头肩底、三角形、箱体突破后跟进。
+ 散户适配：主观判断空间大，易假突破，需配合量能确认。

量价博弈
----

+ 逻辑：通过价量配合判断多空力量与资金意图。
+ 散户适配：有一定看盘经验者，可作选股与择时的辅助分析工具，适用面广、容错中等。

打板情绪
----

+ 逻辑：A股特有的涨停板战法、龙头战法。依托涨停板结构、情绪周期（冰点—高潮—退潮）与连板梯队地位做极短线博弈。
+ 散户适配：*高风险高难度*，需极强盘感和执行速度，多数散户不适合，仅作了解。


基本面类
====

价值投资
----

+ 逻辑：买入PE/PB低于历史或行业均值、有安全边际的公司，等待价值回归。
+ 散户适配：*最适合散户的策略之一*。信息虽劣势，但可聚焦公开财报、低频交易、无需盯盘。难点在"价值陷阱"识别和长期忍受浮亏。

成长股投资
----

+ 逻辑：买入营收/利润高增长公司，赚业绩增长的钱。
+ 散户适配：需判断行业景气度和成长持续性，难度较高，易在高估值时接盘。适合有行业认知者。

股息红利策略
----

+ 逻辑：买入高股息率、分红稳定的公司（银行、公用事业、煤炭等），赚分红 + 温和增长。
+ 散户适配：*非常适合稳健型散户*。波动小、有现金流、可长期持有，A股红利ETF可直接参与。

合理价格成长
----

+ 逻辑：PEG < 1，兼顾估值与成长，介于价值与成长之间。
+ 散户适配：需一定财务分析能力，但比纯成长稳健。


量化配置类
====

指数定投
----

+ 逻辑：定期定额买入宽基指数，摊平成本，赚市场长期增长。
+ 散户适配：*最普适、最省心*。无需择时选股，克服人性弱点。

行业ETF轮动
----

+ 逻辑：在景气行业ETF间切换。
+ 散户适配：比个股轮动风险低，*需一定行业判断*。

多因子选股
----

+ 逻辑：用估值、动量、质量、波动等因子打分选股，分散持有。
+ 散户适配：*可以直接用现成因子ETF/指数增强基金*，无需自己建模。自己编程建模对多数散户门槛高。

网格交易
----

+ 逻辑：设定价格区间，跌买涨卖，赚震荡的钱。
+ 散户适配：适合震荡品种（ETF、可转债），需纪律和资金分层。趋势单边市会"卖飞"或"套牢"。


事件驱动类
====

事件驱动类散户信息劣势明显，*不建议作为主策略*，仅可小仓位博弈。

财报超预期
----

+ 逻辑：业绩预告/财报超预期后买入，赚预期差。
+ 散户适配：信息反应慢于机构，难度大，易追高。

并购重组政策等主题
----

+ 逻辑：重组停牌、政策利好主题炒作。
+ 散户适配：*投机性强、信息不对称严重*，散户多处于劣势，仅小仓位参与。

分红除权送转
----

+ 逻辑：高送转、填权行情。
+ 散户适配：A股高送转炒作降温，需谨慎。


低风险套利类
====

新股申购
----

+ 逻辑：A股新股申购中签后卖出，赚一二级价差。
+ 散户适配：*几乎零门槛的增强收益*，需持有市值底仓，中签率低但风险极小。

可转债轮动
----

+ 逻辑：买入"双低"（低价格+低溢价率）可转债，下有债底、上有股性。
+ 散户适配：*很适合散户的低风险增强策略*，T+0、无涨跌停（有临停）、债底保护。

折溢价套利
----

+ 逻辑：LOF/ETF折溢价、分级基金套利。
+ 散户适配：需工具和速度，机会少，门槛较高。

国债逆回购
----

+ 逻辑：闲余资金赚无风险利息。
+ 散户适配：*人人适用*，管理现金仓位。


组合类
====

核心-卫星策略
----

+ 逻辑：核心仓位（指数/红利）打底，卫星仓位（趋势/主题）增强。
+ 散户适配：*强烈推荐*。兼顾稳健与弹性，避免单一策略失效。

股债平衡
----

+ 逻辑：股票与债券按固定比例配置，定期再平衡。
+ 散户适配：适合风险承受中等者，波动可控。
